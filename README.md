# Mystic Dice Quest 🎲

Mystic Dice Quest is a beginner-friendly Python game built with **Pygame**. Players explore a mysterious cavern by rolling a magical die. Each roll triggers a random event: traps, potions, gold, or nothing at all. Survive the hazards and collect 50 gold to win!

---

## 🕹️ Gameplay

- 🎲 Click **ROLL** to roll the die
- 💥 Rolls 1–2: Lose 20 HP (Trap)
- 👀 Rolls 3–4: Nothing happens
- 💰 Roll 5: Gain 10 gold
- 🧪 Roll 6: Heal 15 HP

**Win Condition:** Reach 50 gold  
**Lose Condition:** Health drops to 0
